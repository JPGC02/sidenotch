SideNotch

Barra lateral com o uso das suas IAs e as aprovações do Claude Code. Passe o mouse na borda da tela para abrir; arraste pelo ⋯ no topo da barra para mover.

Posição e aparência

Provedores

Claude Code — aprovações, sessões e avisos

Instala hooks HTTP em ~/.claude/settings.json. A barra recebe pedidos de permissão (Permitir / Sempre / Negar / Responder), aprovação de plano, perguntas, e mostra quando cada sessão terminou, está esperando você ou teve algo negado no auto mode.

Maestri (Wire)

No Maestri: Configurações → Wire → ligue o servidor → aba Pareamento (código de 6 dígitos) ou Manual (senha). A barra mostra os terminais do Maestri em Sessões, avisa quando um agente precisa de atenção e responde prompts S/n com Aprovar/Rejeitar.
